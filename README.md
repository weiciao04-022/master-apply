# master-apply｜研究所申請手帳

個人用的海外研究所申請管理網站：今日任務、申請路線圖、選校比較、文件與作品、每週回顧與申請看板。
React + TypeScript + Vite，資料存在瀏覽器的 IndexedDB，不需要登入。

## 開始使用

```bash
npm install
npm run dev      # 開發模式，打開終端機顯示的網址
npm test         # 排程、日期、備份、IndexedDB 的單元測試
npm run build    # 輸出到 dist/，可放到 GitHub Pages（base 已設為 ./）
```

> 資料只保存在目前這個瀏覽器。換瀏覽器、清除網站資料或用無痕視窗都看不到，請定期到「設定」匯出 JSON 備份。

## 頁面

| 頁面 | 內容 |
| --- | --- |
| 今天 | 今日 1–3 項任務（打勾／延後／拆小）、最近期限、本週重點、階段進度、等待他人與待查證 |
| 路線圖 | 年度／月份／本週視圖；官方截止日、自行設定期限、暫估日期分開標示；目標入學年度變更可先預覽再套用 |
| 選校 | 表格／卡片、依國家／領域／狀態篩選；學程頁有材料清單、送件紀錄、招生資訊來源標示、官方資訊更新差異比對 |
| 文件 | 共用素材庫（版本、外部連結、適用學程、待修改）、推薦信邀請與提交追蹤 |
| 回顧 | 本週完成／未完成、下週最多三項重點、熱度日曆、各學程申請看板 |
| 設定 | 休息日、每週時間上限、忙碌期間、階段範圍、匯率、背景、JSON／CSV 備份 |

## 資料模型（`src/types.ts`）

各自一張 IndexedDB object store，以 ID 關聯：

- `programs` 學程（同校不同學程分開）・`sources` 招生資訊來源（適用入學年度、查核日期、涵蓋欄位）・`revisions` 官方資訊更新（保留舊值，待確認後才套用）
- `milestones` 日期（`official`／`self`／`estimate`）・`phases` 申請階段
- `tasks` 任務（`mine`／`waiting`／`verify`、前置任務、母子任務、相關學程與文件）
- `assets` 共用素材（版本紀錄）・`requirements` 各學程材料（對應素材；已上傳與已提交分開）・`recommenders` 推薦人
- `applications` 送件、面試、結果・`reviews` 每週回顧・`meta.settings` 設定

## 排程規則（`src/lib/scheduler.ts`）

- 只排「我需要執行」且沒有未完成子任務的任務；等待他人與待查證不算每日工作
- 依期限 → 重要性 → 建立時間排序，前置任務完成前不排後續任務
- 每天最多 `maxTasksPerDay` 項，並遵守「每週時間上限 ÷ 工作日」的每日分鐘數
- 休息日（預設週四、週日）不排；忙碌期間只排允許的類別（預設 2026/12/24 前只排英文／TOEFL）
- 逾期任務在隔天自動分散到之後有空位的工作日，不會全部堆到同一天
